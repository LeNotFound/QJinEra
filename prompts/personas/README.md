# QJinEra Personas

欢迎来到 QJinEra 的人设 (Persona) 目录！这里存放着系统使用的格式化角色设定文件。

## 🌟 强烈推荐：UPEX (Universal Persona Exchange)

想要获取更多优质的人格预设，或者寻找统一、标准化的人格描述格式？

这里的角色配置文件采用了 **[UPEX (Unified Prompt Expression)](https://github.com/LeNotFound/UPEX)** 规范编写。UPEX 提供了一种更结构化、更利于 LLM 理解的 Prompt 组织方式。

你可以参考这个基础模板来为 QJinEra 编写新的 Persona：
👉 [查看 UPEX basic.ujson 示例](https://github.com/LeNotFound/UPEX/blob/main/examples/basic.ujson)

UPEX 致力于提供跨平台、高度可复用且结构清晰的 Prompt 人设框架。无论你是想要分享自己精心调教的角色，还是想要寻找灵感，都欢迎来到 UPEX！
